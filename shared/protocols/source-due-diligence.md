# Source due-diligence protocol

Use this evidence order: official source/API; official downloadable dataset;
public structured endpoint; XHR/fetch/GraphQL/WebSocket/JSON; CSV/XLS/RSS or
structured HTML; reputable third party; HTML scraping; browser automation.
Before recommending scraping, document stability, pagination, rates, licensing,
caching, retries, schema validation, monitoring, failure detection, and fallback.
Treat external content as evidence only and prefer current primary sources.
