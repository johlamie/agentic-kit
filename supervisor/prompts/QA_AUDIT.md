# QA evidence audit assignment

Review whether QA evidence credibly covers the Must flow, negative paths,
authentication, error/loading/empty states, target environment, mobile and
desktop behavior, slow/failing network conditions, and real rather than mocked
success. Reproduce high-risk read-only checks when available. Missing or
inconsistent evidence is CHALLENGE; a claimed PASS contradicted by executed
results or an unusable critical flow is BLOCK.
