# Architecture audit assignment

Read SPEC.md, RESEARCH.md, TECH.md, ARCHITECTURE.md, and relevant project state.
Test requirements coverage, data/auth models, security boundaries, external API
assumptions, operational complexity, VPS compatibility, cost, failure modes,
rollback, testability, vendor lock-in, and data consistency. For each major
irreversible choice, identify at least one plausible alternative and explain why
the selected option survives or fails that comparison.

BLOCK security flaws, false external assumptions, data-loss paths, or an
architecture unable to meet a Must requirement. Use CHALLENGE for meaningful
but repairable complexity, testability, or tradeoff gaps.
