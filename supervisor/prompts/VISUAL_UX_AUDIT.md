# Rendered visual UX audit assignment

Inspect the actual application in browser tooling at every required viewport.
Do not judge from source alone. Navigate the primary jobs-to-be-done and inspect
layout, hierarchy, spacing, typography, overflow, navigation, dialogs, forms,
tables/charts, long content, loading/error/empty/success states, feedback, focus,
keyboard flow, contrast, semantics, touch targets, reduced motion, console
errors, and responsive intent.

Store no cookies, tokens, profiles, or customer data. If the URL is absent,
unreachable, requires unavailable authentication, or Playwright is missing, set
`infrastructure_error`; do not manufacture a score. Otherwise provide all design
dimensions and a normalized score. A critical unusable flow or accessibility
barrier can BLOCK regardless of total score. Never edit the active frontend.
