---
name: retrospective
description: Record actionable lessons, verification evidence and a handoff after significant work, a failure, or a requested checkpoint in an agentic project.
---

Read `.agentic/CONTRACT.md`. Update PROJECT_STATE with actual work, checks,
blockers and next steps. Append only durable lessons and explicitly supersede
outdated decisions. Attribute entries to the actual tool, role and session.
Subagents return memory proposals to the orchestrator instead of racing to
edit shared state.

Record missing skills, agents, MCPs and external capabilities with concrete
remediation. Keep Supervisor producer/auditor attribution separate; no audit
or permission downgrade to make a result pass. Use `agentic checkpoint` to
record the summary, test results, next step and relevant files. Propose rule
changes as diffs within the user's authorized scope. Report the outcome and
remaining work concisely in French.
