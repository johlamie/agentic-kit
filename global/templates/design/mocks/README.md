# Rendered mocks
Self-contained HTML (inline CSS, real French copy, no external assets) rendered
with a browser before anyone codes:

- `direction-a.html`, `direction-b.html` — the core screen in each direction, for G3.
- `core.html` — the chosen direction, using the final tokens. Builders reproduce it.

Screenshots at 390×844 and 1440×900 go in `shots/<mock>-<width>.png` and are
what the user sees at G3. ASCII alone is not a direction.
