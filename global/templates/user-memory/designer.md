# Designer memory
> User scope: the founder's confirmed taste and constraints, across projects.
> Seeded by the kit; the orchestrator appends confirmed preferences, tagged by
> project and date. Never store secrets. Aesthetics of one project (palette,
> typeface, emblem) are NOT preferences: record the reason the founder gave.

## Hard constraints
- French-first UI with proper typography (espaces insécables, capitales accentuées).
- Low-end Android and slow networks are the reference device and network.
- Currency and formats: XOF when relevant; dates in full French.

## Confirmed taste (see design-system/PRINCIPLES.md)
- [2026-09-27][sceau] Prefers calm, airy, clean screens on the shadcn/ui + Tailwind
  baseline; originality comes from structure, not decoration.
- [2026-09-27][sceau] Public pages must not look like admin tools: rejected a
  sidebar + history list + full-colour verdict banner for a public verification page.
- [2026-09-27][sceau] Liked: separating distinct kinds of information (the person
  vs the certificate's traceability); a meaningful emblem (the seal) that gives
  the page character. Two columns are right when the content calls for them,
  not by default.
- [2026-09-27] Mobbin is optional inspiration, never the main compass.
