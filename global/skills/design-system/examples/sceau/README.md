# Example — Sceau (public diploma verification)

A complete `design/` deliverable, kept as the **quality bar**, not as a style to
copy. Study how it applies `../../PRINCIPLES.md`; then design the next product
its own way.

- `DESIGN.md` … `system.json`: the numbered system (`agentic design-lint --spec` PASS).
- `mocks/core.html?state=home|loading|valid|revoked|notfound`: the rendered core
  screen, Tailwind v4 + shadcn markup. `icons.js` inlines lucide icons.
- `mocks/shots/`: renders at 390 and 1440, plus the rejected direction B.
- `G3.md`: the comparison and the founder's decision.

What the founder liked (27/09/2026): pleasant to the eye; the page separates the
student's information from the certificate's traceability; the seal gives it
character. What was rejected: direction B, whose sidebar, history list and full
colour verdict banner read as an admin tool on a public page.

What is specific to Sceau and must NOT be reused by default: the green, Fraunces,
the seal, the two-column split. The next product finds its own equivalents.
References in `refs/` were written from memory (no Mobbin), as flagged there.
