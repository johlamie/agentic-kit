# G3 — Vérification de diplômes (aperçu)

Base commune : shadcn/ui + Tailwind v4, lucide. Écran cœur : résultat d'une vérification.
Références : de mémoire, **sans Mobbin** (dans le kit, ce serait un BLOCK sans ton accord).

| | A « Registre » | B « Scanner » |
|---|---|---|
| Pour qui | toute personne qui ouvre le lien ou scanne le QR | recruteurs, écoles, services RH qui vérifient souvent |
| Navigation | barre haute minimale, la page est un document | onglets en bas (mobile), sidebar + historique (desktop) |
| Entrée | le nom du titulaire en serif, sous un sceau | un bandeau de verdict plein, lisible à 2 m |
| Structure | fiche officielle + colonne « Traçabilité » | liste-détail : historique → détail |
| Typo | Fraunces (titres) + Instrument Sans | Manrope seule |
| Accent / rayon | vert profond, 0,375 rem (net, institutionnel) | bleu encre + vert succès, 1 rem (doux, applicatif) |
| Moment signature | le sceau guilloché | le bandeau de verdict |
| États montrés | Authentique | Authentique, Introuvable, Révoqué (historique) |

Force A : crédibilité, preuve partageable, parfait pour le lien public imprimé sur le diplôme.
Risque A : moins adapté à un usage répété par un même vérificateur.
Force B : rapidité, historique, usage terrain sur Android.
Risque B : plus « app » que « document officiel » pour un tiers qui reçoit le lien.

Piste : A pour la page publique de preuve, B pour l'espace des vérificateurs.

## Décision (27/09/2026)
Direction A retenue pour le public. Raisons données : plus agréable à l'œil ;
séparation en deux (informations de l'étudiant / traçabilité du certificat) ;
le sceau donne une meilleure apparence. B est lue comme une interface
d'administration : sa structure (sidebar, historique, bandeau plein) est
réservée au futur espace des administrateurs.
