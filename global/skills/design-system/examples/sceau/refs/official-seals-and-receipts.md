# Référence : reçus et justificatifs officiels numériques
Source : **de mémoire, Mobbin non disponible**. Valeurs approximatives.

- Pourquoi : l'attestation et la fiche doivent se lire comme une pièce, pas comme une app.
- Grid : une colonne de 560–720 px pour le document, filets de 1 px entre les lignes.
- Spacing rhythm : cellules 16–24 px, pas d'ombre, contraste par les filets.
- Type : un titre à forte personnalité (serif ou display), le reste en sans neutre.
- Components : emblème ou tampon, numéro de pièce en chiffres tabulaires, date lisible.
- Décision sous-jacente : l'emblème porte la confiance ; nous en faisons un composant à états (valide, barré, vide).
