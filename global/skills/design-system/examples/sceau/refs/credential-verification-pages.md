# Référence : pages publiques de vérification de certificats
Source : **de mémoire, Mobbin non disponible dans cet aperçu** (dans le kit : BLOCK
sans accord écrit). Valeurs approximatives, à remesurer sur Mobbin.

- Pourquoi pour notre SPEC : même job (étape 2) — un tiers ouvre un lien et doit croire le document.
- Grid : conteneur ~1100–1200 px, 2 colonnes (document + métadonnées), gouttière ~48 px.
- Spacing rhythm : 8 / 16 / 24 / 48 px.
- Radius : 4–8 px sur les cartes ; badges plus petits.
- Type : nom du titulaire 32–40 px, métadonnées 14 px, valeurs 16 px medium.
- Components : badge de statut, fiche clé/valeur, frise d'événements, actions partager/télécharger.
- Color roles : fond clair neutre, un accent de confiance, rouge réservé au retrait.
- States : valide, expiré/révoqué ; « introuvable » souvent absent — à concevoir.
- Décision sous-jacente : la preuve est lisible sans compte, et le statut précède l'identité.
